# Career-Ops provider inventory, classified for a Brazil-based remote tech / AI / automation / integrations / RevOps / solutions-engineering candidate

Source: upstream `career-ops` at commit 55a5165 (MIT), read offline. No network request was made and no provider code was run. Every row was checked against `providers/<name>.mjs` (endpoint constants, emitted job fields, pagination constants) and against `docs/SUPPORTED_JOB_BOARDS.md`. Tests: every provider has `tests/providers/<name>.test.mjs`; extra test or fixture files are listed where they exist.

110 non-helper provider modules, plus 2 Playwright scanners that live outside `providers/` (`scan-dayforce.mjs`, `scan-interamt.mjs`) listed at the end of the table for completeness = 112 rows.

## Legend

- **Kind**: ATS = multi-tenant ATS (one entry per employer tenant); AGG = board-wide aggregator / job board; EMP = single employer; GOV = government / public employment service; NICHE = niche or curated board; INFRA = not a source.
- **Acq**: API = public JSON API; GQL = GraphQL; ALG = public Algolia index; RSS / Atom / XML feed; SSR = server-rendered HTML parser (incl. `__NEXT_DATA__` / JSON-LD in page); PW = Playwright browser.
- **Desc**: `src` = whether the source payload carries a body; `emit` = whether the upstream provider actually puts it on the job; `D` = per-posting detail fetch (opt-in unless stated). Many board feeds carry a body that the upstream provider throws away because its scanner only filters on title/location.
- **Loc / Sal / Date**: what the provider emits. Sal Y = structured `{min,max,currency}`.
- **Risk / Effort**: L/M/H. Effort = effort to port into CareerAgent.
- **UA spoof**: provider sends a browser-like User-Agent (`BROWSER_LIKE_USER_AGENT`) instead of the default `career-ops/1.0` one. Not browser automation, but a soft anti-bot accommodation and a maintenance signal.
- Permission (robots.txt / terms) is NOT re-evaluated here; upstream's own notes are quoted where relevant. CareerAgent's own policy (ADR-0018) must still be applied per source.

## (b) Top 15 for this profile, ranked

1. **Greenhouse**: biggest share of remote-first US/EU SaaS and AI companies, one zero-auth request per board with full body (`content=true`), location and date. The single highest-yield family.
2. **Ashby**: the default ATS of current AI startups; plain-text body and structured compensation in the list response.
3. **Lever**: same class as Greenhouse, full body inline, EU host supported; many SaaS / RevOps / solutions roles.
4. **Workable**: per-account widget API (`details=true`) returns the full list with bodies in one call; very common among SMBs and agencies hiring LATAM. Use the widget endpoint, not the global search index.
5. **Get on Board**: the LATAM tech board; remote-heavy, Brazil-reachable, structured JSON:API. Upstream drops the body; compose it from the split attributes.
6. **Gupy**: the Brazilian market itself; full description in the list, `workplaceType` filter for remote. Upstream now calls `portal.gupy.io/api/job-search/jobs` and treats `employability-portal.gupy.io` as a retired alias, which is the most actionable finding for CareerAgent's 2026-10-02 blocker.
7. **Himalayas**: publishes a real hiring scope (`locationRestrictions`), salary and full body; upstream only reads the first 50 rows.
8. **Remotive**: `candidate_required_location` is a hiring scope; strong SaaS / customer success / solutions mix.
9. **We Work Remotely**: `region` is the employer's hiring scope; high signal, small window.
10. **Jobicy**: `jobGeo` hiring scope with LATAM and Brazil slices.
11. **Agentic Engineering Jobs**: exactly the AI-agents / automation niche, documented OpenAPI, body + salary + date, polite rate limit.
12. **Recruitee**: best list payload of any ATS (body, date, annualized salary); EU startups with remote roles.
13. **RemoteOK**: worldwide remote, body and salary in source; robots names ClaudeBot, so owner-run only.
14. **SmartRecruiters**: multinationals with Brazilian hubs and LATAM shared-service centres; list + optional detail fetch. Permission must be re-checked (CareerAgent recorded a robots disallow on the API host).
15. **Teamtailor**: RSS per tenant, location tags plus a Remote fallback; many remote-first European SaaS employers.

Runners-up: Hacker News Who is hiring (remote AI startups, free-text parse), Breezy and Zoho Recruit (staffing agencies placing LATAM talent), Rippling, HiringRoom (LATAM ATS not yet in CareerAgent), Getro / Consider (VC portfolio networks that emit the original ATS link), Working Nomads, 4 Day Week, Generalist World (RevOps / operator roles), Workday.
