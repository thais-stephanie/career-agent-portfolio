> O Career Agent está atualmente na versão **Alpha v0.1.0-alpha.2**, com o **Resume Tailor Beta** incluído.

## Instalação mais fácil: Windows

1. Abra a página de [Releases](https://github.com/thais-stephanie/career-agent-portfolio/releases/tag/v0.1.0-alpha.2).
2. Baixe `Career-Agent-v0.1.0-alpha.2-Windows.zip`.
3. Clique com o botão direito no ZIP, escolha **Extrair tudo** e abra a pasta extraída.
4. Dê dois cliques em **Start-Career-Agent.cmd**. Mantenha essa janela aberta.
5. Aguarde a configuração. Seu navegador abrirá automaticamente.

Você não precisa instalar Python ou Node manualmente. O launcher baixa o uv, uma ferramenta que gerencia Python e pacotes, caso ele ainda não esteja instalado. O uv instala o Python 3.12 e as dependências travadas da versão. A primeira configuração precisa de internet.

Use uma pasta em que você tenha permissão de escrita. Evite `Program Files`.

[Ajuda para a primeira execução](FIRST_RUN.md).

## Como abrir novamente

Dê dois cliques no mesmo launcher, dentro da mesma pasta.

Seus dados permanecem salvos ali.

Para encerrar os dois aplicativos, volte à janela do launcher e pressione **Ctrl+C**.

Antes de migrar para uma nova versão, faça backup dos seus dados.

## O que ele faz

| Etapa | O que você recebe |
|---|---|
| Descobrir vagas | 26 fontes integradas entre redes ATS, job boards remotos e agregadores, além da possibilidade de importar uma vaga manualmente. Cada vaga mantém sua fonte e a origem da coleta. |
| Verificar elegibilidade | Restrições de contratação ficam separadas das suas preferências. “Remoto” não significa “disponível no mundo inteiro”. Informações ausentes continuam não resolvidas. |
| Entender o Search Fit | Uma pontuação transparente que compara informações da vaga com as suas preferências de busca, mostrando os motivos e o que não foi informado. Não é uma probabilidade de contratação. |
| Revisar Career Evidence | O sistema extrai sugestões do seu currículo para você confirmar, editar ou rejeitar. Importar um texto não transforma automaticamente aquilo em experiência confirmada. |
| Acompanhar candidaturas | Você pode salvar status e observações das vagas às quais decidiu se candidatar. |

## Fontes de vagas

O Career Agent possui atualmente **26 fontes de vagas integradas** com cobertura global, dos Estados Unidos, Europa, LATAM e Brasil.

| Cobertura | Fontes integradas |
|---|---|
| ATS e sistemas de empresas | Greenhouse, Lever, Ashby, Workday, Workable, Teamtailor, Rippling, Recruitee, Comeet, Gupy |
| Job boards remotos e globais | We Work Remotely, Remote OK, Himalayas, Jobicy, 4 Day Week, Remotive, Working Nomads, Dynamite Jobs, Arbeitnow |
| Redes e agregadores | a16z Speedrun, Jobgether, Jooble |
| LATAM e Brasil | Get on Board, Recruiterflow, Avlis Talent, Programathor |

Algumas fontes oferecem inventários estruturados mais completos. Outras disponibilizam apenas janelas de vagas recentes, feeds limitados ou resultados com metadados.

Por isso, o Career Agent registra o nível de cobertura de cada fonte em vez de tratar todos os conectores como equivalentes.

[Ver permissões e observações de cobertura das fontes →](docs/SOURCES.md)

### LinkedIn

**O LinkedIn não é coletado automaticamente.** O LinkedIn proíbe acesso automatizado sem permissão por escrito, então o Career Agent o oferece apenas como um link de busca que você abre no seu navegador. Você pode colar uma vaga do LinkedIn na importação manual e importar a exportação em PDF do seu próprio perfil do LinkedIn para revisão.

## Resume Tailor Beta

Abra **Resume Tailor Beta** na barra lateral.

A partir de uma vaga, escolha **Copy job description**, abra o Tailor e cole o conteúdo em **Tailor resume**.

Crie um perfil de candidato, adicione um currículo-base e documentos de apoio, revise suas evidências, analise a vaga, verifique correspondências e gaps, gere o currículo, edite, valide e exporte.

As exportações em Markdown e Word funcionam sem IA.

A exportação em PDF precisa do Microsoft Word ou LibreOffice instalado localmente. Caso nenhum deles esteja disponível, o aplicativo informa que o PDF não pode ser gerado.

Os dois módulos mantêm bases de evidências separadas. Nenhum perfil ou evidência é sincronizado automaticamente.

**Search Fit e Tailor Match respondem perguntas diferentes.**

Search Fit avalia como uma vaga combina com a sua busca.

Tailor Match verifica quais requisitos da vaga podem ser sustentados pelas evidências da sua experiência.

Texto gerado nunca se transforma automaticamente em Career Evidence confirmado.

Experiência sem evidência não deve aparecer como afirmação no currículo.

Veja as [garantias de evidência e arquitetura](docs/ARCHITECTURE.md).

## Privacidade

Suas configurações, vagas, anotações e evidências ficam armazenadas localmente.
O Resume Tailor mantém os documentos de origem que você adiciona ao workspace dele.
O Career Agent extrai o texto do currículo sem manter o arquivo original enviado.
Provedores opcionais de IA podem receber conteúdo quando você os configura e usa explicitamente.
A coleta de vagas e a abertura de links de empresas também usam internet.
O produto não implementa telemetria.

Leia o [modelo de privacidade](docs/PRIVACY.md) para detalhes sobre armazenamento, backups, clipboard e outros limites do sistema.

## O que ele deliberadamente não faz

O Career Agent não envia candidaturas automaticamente.
Ele não promete entrevistas.
Ele não transforma uma vaga remota em elegibilidade global.
Ele não esconde gaps de evidência.
Ele não trata saída de modelo como experiência profissional confirmada.

## Instalação pelo terminal

<details>
<summary>Configuração manual para desenvolvedores</summary>

### Windows

Abra o menu Iniciar, digite `PowerShell` e abra o Windows PowerShell.

No macOS, abra **Aplicativos → Utilitários → Terminal**.

No Linux, abra o aplicativo de Terminal que você já utiliza.

Instale o [uv](https://docs.astral.sh/uv/getting-started/installation/), baixe e extraia o ZIP do código-fonte pela página de [Releases](https://github.com/thais-stephanie/career-agent-portfolio/releases/tag/v0.1.0-alpha.2).

Depois, no terminal, use `cd` seguido pelo caminho da pasta entre aspas.

Execute:

```powershell
uv sync --locked --python 3.12
uv run python scripts/launch.py
````

Você não precisa instalar Python manualmente.

Windows é a plataforma validada para esta release.

Para usar portas diferentes:

```powershell
uv run python scripts/launch.py --port 8875
```

O Resume Tailor usará a porta seguinte, `8876`.

</details>

## Demo

Dê dois cliques em **Start-Demo.cmd** ou execute:

```powershell
uv run python scripts/launch.py --demo
```

A demo cria vagas fictícias e um candidato sintético chamado Alex Morgan em um armazenamento separado.

Pare o modo pessoal antes de iniciar a demo nas mesmas portas.

A demo não utiliza nenhum provedor de IA.

## Limitações

Career Agent está em Alpha.

Resume Tailor está em Beta.

A disponibilidade das fontes pode mudar quando job boards alteram interfaces ou regras de acesso.

Os leitores de idioma ainda não cobrem todos os casos.

A elegibilidade pode permanecer desconhecida quando uma vaga não informa dados suficientes.

A revisão das evidências continua sendo responsabilidade do usuário.

Career Agent e Resume Tailor ainda não compartilham perfis ou evidências automaticamente.

A exportação em PDF e a contagem exata de páginas dependem de um renderizador local.

O aplicativo é local e voltado para um único usuário. Não oferece acesso remoto nem sincronização em nuvem.

A instalação inicial precisa de internet.

Windows é a plataforma validada para esta release.

A conversão de PDF usando Microsoft Word foi testada.

LibreOffice não estava instalado no ambiente de validação.

Nenhum provedor hospedado de IA foi testado ao vivo durante a validação da Alpha 2.
