# Resume Tailor Beta

Included companion for Career Agent. Use the root [launcher and installation guide](../../README.md). The shared launcher installs Python 3.12 and scopes personal and demo data to separate local directories. Do not use the old standalone launcher for this edition.

Started by the Career Agent launcher, Resume Tailor follows the active local profile: it opens on the posting you came from, lists the jobs that profile is tracking, and can build a base resume from the confirmed Career Profile or from an uploaded PDF, Word (.docx) or Markdown file. Confirmed Career Profile statements are imported only when you ask; nothing flows back into Career Agent's evidence, and a status changed here is written by Career Agent. Started on its own, it is the standalone app with a candidate selector.

Review suggestions, inspect job requirements and evidence matches, generate, validate, edit and export Markdown, DOCX or locally rendered PDF. Back up a candidate from its menu. AI is optional and defaults to none. Source documents are retained locally; configured AI operations can send content to the selected endpoint. The interface is in English; error messages are in English and Brazilian Portuguese.
