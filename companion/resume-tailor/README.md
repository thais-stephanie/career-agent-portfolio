# Resume Tailor Beta

Included companion for Career Agent. Use the root [launcher and installation guide](../../README.md). The shared launcher installs Python 3.12 and scopes personal and demo data to separate local directories. Do not use the old standalone launcher for this edition.

Create a candidate, add a base resume and source documents, review suggestions, inspect job requirements and evidence matches, generate, validate, edit and export Markdown, DOCX or locally rendered PDF. Back up a candidate from its menu. AI is optional and defaults to none. Source documents are retained locally; configured AI operations can send content to the selected endpoint.

See [privacy](../../docs/PRIVACY.md), [architecture](ARCHITECTURE.md), [license](LICENSE) and [modification notice](NOTICE). Search Fit is not Tailor Match. No evidence or profile synchronization is implemented.
