> Career Agent se encuentra actualmente en **Alpha v0.1.0-alpha.2**, con **Resume Tailor Beta** incluido.
> La aplicación es funcional y continúa en desarrollo activo. Search Fit explica cómo una vacante coincide con tus preferencias de búsqueda. No estima tus probabilidades de ser contratado.

## Instalación más sencilla: Windows

1. Abre la página de [Releases](https://github.com/thais-stephanie/career-agent-portfolio/releases/tag/v0.1.0-alpha.2).
2. Descarga `Career-Agent-v0.1.0-alpha.2-Windows.zip`.
3. Haz clic derecho sobre el ZIP, selecciona **Extraer todo** y abre la carpeta extraída.
4. Haz doble clic en **Start-Career-Agent.cmd**. Mantén esa ventana abierta.
5. Espera a que termine la configuración. Tu navegador se abrirá automáticamente.

No necesitas instalar Python ni Node manualmente. El launcher descarga uv, una herramienta que administra Python y sus paquetes, si todavía no está instalado. Después, uv instala Python 3.12 y las dependencias bloqueadas de la versión.

La primera configuración necesita conexión a internet.

Usa una carpeta en la que tengas permisos de escritura. Evita `Program Files`.

[Ayuda para la primera ejecución](FIRST_RUN.md).

## Cómo abrirlo de nuevo

Haz doble clic en el mismo launcher dentro de la misma carpeta.
Tus datos permanecen guardados allí.
Para detener ambas aplicaciones, vuelve a la ventana del launcher y presiona **Ctrl+C**.
Antes de pasar a una nueva versión, haz una copia de seguridad de tus datos.

## Qué hace

| Etapa | Qué obtienes |
|---|---|
| Descubrir empleos | 26 fuentes integradas entre redes ATS, portales de empleo remoto y agregadores, además de la opción de importar una vacante manualmente. Cada vacante conserva su fuente y la procedencia de la recopilación. |
| Comprobar elegibilidad | Las restricciones de contratación se mantienen separadas de tus preferencias. “Remoto” no significa “disponible en todo el mundo”. La información ausente permanece sin resolver. |
| Entender Search Fit | Una puntuación transparente que compara la información de la vacante con tus preferencias de búsqueda y muestra los motivos y la información que falta. No es una probabilidad de contratación. |
| Revisar Career Evidence | El sistema extrae sugerencias de tu currículum para que puedas confirmarlas, editarlas o rechazarlas. Importar texto no lo convierte automáticamente en experiencia confirmada. |
| Seguir tus postulaciones | Puedes guardar el estado y tus notas sobre las vacantes a las que decidas postularte. |

## Fuentes de empleo

Career Agent cuenta actualmente con **26 fuentes de empleo integradas** con cobertura global, de Estados Unidos, Europa, LATAM y Brasil.

| Cobertura | Fuentes integradas |
|---|---|
| ATS y sistemas de empresas | Greenhouse, Lever, Ashby, Workday, Workable, Teamtailor, Rippling, Recruitee, Comeet, Gupy |
| Portales remotos y globales | We Work Remotely, Remote OK, Himalayas, Jobicy, 4 Day Week, Remotive, Working Nomads, Dynamite Jobs, Arbeitnow |
| Redes y agregadores | a16z Speedrun, Jobgether, Jooble |
| LATAM y Brasil | Get on Board, Recruiterflow, Avlis Talent, Programathor |

Algunas fuentes ofrecen inventarios estructurados más completos. Otras proporcionan ventanas de vacantes recientes, feeds limitados o resultados basados principalmente en metadatos.

Por eso, Career Agent registra el nivel de cobertura de cada fuente en lugar de tratar todos los conectores como equivalentes.

[Ver permisos y notas de cobertura de las fuentes →](docs/SOURCES.md)

## Resume Tailor Beta

Abre **Resume Tailor Beta** desde la barra lateral.

Desde una vacante, selecciona **Copy job description**, abre Tailor y pega el contenido en **Tailor resume**.
Crea un perfil de candidato, agrega un currículum base y documentos de apoyo, revisa tu evidencia, analiza la vacante, inspecciona coincidencias y gaps, genera el currículum, edítalo, valídalo y expórtalo.

Las exportaciones a Markdown y Word funcionan sin IA.
La exportación a PDF necesita Microsoft Word o LibreOffice instalado localmente. Si ninguno está disponible, la aplicación informa que el PDF no puede generarse.
Los dos módulos mantienen almacenes de evidencia separados. Ningún perfil ni evidencia se sincroniza automáticamente.

**Search Fit y Tailor Match responden preguntas diferentes.**

Search Fit evalúa cómo una vacante coincide con tu búsqueda.
Tailor Match comprueba qué requisitos de la vacante pueden respaldarse con evidencia de tu experiencia.
El texto generado nunca se convierte automáticamente en Career Evidence confirmado.
La experiencia que no tenga evidencia suficiente no debe aparecer como una afirmación en el currículum.

Consulta las [garantías de evidencia y arquitectura](docs/ARCHITECTURE.md).

## Privacidad

Tus configuraciones, empleos, notas y evidencias se almacenan localmente.
Resume Tailor conserva los documentos de origen que agregas a su workspace.
Career Agent extrae el texto del currículum sin conservar el archivo original que subiste.
Los proveedores opcionales de IA pueden recibir contenido cuando los configuras y utilizas explícitamente.
La recopilación de empleos y la apertura de enlaces de empresas también utilizan internet.

El producto no implementa telemetría.

Consulta el [modelo de privacidad](docs/PRIVACY.md) para obtener detalles sobre almacenamiento, copias de seguridad, portapapeles y otros límites del sistema.

## Lo que deliberadamente no hace

Career Agent no envía postulaciones automáticamente.
No promete entrevistas.
No convierte una vacante remota en elegibilidad global.
No oculta gaps de evidencia.
No trata la salida de un modelo como experiencia profesional confirmada.

## Instalación desde el terminal

<details>
<summary>Configuración manual para desarrolladores</summary>

### Windows

Abre el menú Inicio, escribe `PowerShell` y abre Windows PowerShell.

En macOS, abre **Aplicaciones → Utilidades → Terminal**.

En Linux, abre la aplicación de Terminal que utilices normalmente.

Instala [uv](https://docs.astral.sh/uv/getting-started/installation/), descarga y extrae el ZIP del código fuente desde la página de [Releases](https://github.com/thais-stephanie/career-agent-portfolio/releases/tag/v0.1.0-alpha.2).

Después, en el terminal, usa `cd` seguido de la ruta de la carpeta entre comillas.

Ejecuta:

```powershell
uv sync --locked --python 3.12
uv run python scripts/launch.py
````

No necesitas instalar Python manualmente.

Windows es la plataforma validada para esta release.

Para utilizar puertos diferentes:

```powershell
uv run python scripts/launch.py --port 8875
```

Resume Tailor utilizará el puerto siguiente, `8876`.

</details>

## Demo

Haz doble clic en **Start-Demo.cmd** o ejecuta:

## Limitaciones

Career Agent está en Alpha.
Resume Tailor está en Beta.
La disponibilidad de las fuentes puede cambiar cuando los portales de empleo modifican sus interfaces o reglas de acceso.
Los lectores de idioma todavía no cubren todos los casos.
La elegibilidad puede permanecer desconocida cuando una vacante no proporciona suficiente información.
La revisión de las evidencias sigue siendo responsabilidad del usuario.
Career Agent y Resume Tailor todavía no comparten perfiles ni evidencias automáticamente.
La exportación a PDF y el conteo exacto de páginas dependen de un renderizador local.
La aplicación es local y está diseñada para un solo usuario. No ofrece acceso remoto ni sincronización en la nube.
La instalación inicial necesita conexión a internet.
Windows es la plataforma validada para esta release.
La conversión a PDF mediante Microsoft Word fue probada.
LibreOffice no estaba instalado en el entorno de validación.
Ningún proveedor de IA alojado fue probado en vivo durante la validación de Alpha 2.
